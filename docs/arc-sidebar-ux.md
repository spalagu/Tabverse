# 侧边栏 Tab 交互优化

基于 main `e44bd884e48d460e47e95db05eafeb6bdd7b49d4`（0.1.1）。

## 目标与取舍

借鉴 Arc 的侧边栏操作方式，让整理、切换、重命名和定位 tab 更可预期，而不是把 Tabverse 改造成只有网页的浏览器。本轮不继续此前的 V3 实施计划。

Arc 官方说明区分固定入口与临时 tab，并将固定页重置作为独立操作。本轮保留 Tabverse 已有的固定分组、Today、休眠条目、多选和分屏，不新增 Favorites/Spaces 模型，不修改终端/文件生命周期、会话格式、远程协议或自动归档规则。

参考：
- https://resources.arc.net/hc/en-us/articles/19231060187159-Pinned-Tabs-Tabs-you-want-to-stick-around
- https://resources.arc.net/hc/en-us/articles/25619402657303-How-Do-You-Switch-Between-Tabs-Quickly-on-Arc-Desktop

## 已实现的交互

| 操作 | 结果 |
| --- | --- |
| 拖到 tab 上半部 / 下半部 | 分别插入目标前 / 后；跨组移动采用目标分组，放在分组末尾不会误入下一个分组。 |
| 拖到 tab 中部并停留 | 停留 450ms 后才出现左/右分屏提示，松手创建分屏；快速掠过仍是排序。450ms 是本轮设计参数，不是对 Arc 时序的测量值。 |
| 多选后拖动 / 拖回选中项 | 保留原有多选拖动；拖回所选集合本身不改变顺序。 |
| 点击固定网页标题 | 只激活，不再意外重置网址。偏离固定页时，单独的 Return to pinned page 按钮执行重置。 |
| 单击后 Shift 单击 | 以刚才点击的 tab 为范围起点；多选不切换当前内容。 |
| F2 / 双击标题 | 进入重命名。Enter 保存，Escape 取消，普通失焦保存；中文输入法组合期间不会提前提交或取消。 |
| 侧边栏内方向键、Home、End | 移动键盘焦点，Enter/Space 激活。分组支持左右键折叠/展开，Shift+F10 打开上下文菜单。 |
| 切换到列表外的 tab | 仅滚动侧边栏使其可见，不主动把键盘焦点移到该行。 |
| 拖到列表上下边缘 | 列表随拖拽滚动；拖拽结束或取消后停止并清除落点提示。 |
| 鼠标移入一行 | 分享/关闭按钮显现，但标题可用宽度不变化。行高从 30px 调整为 36px，仍使用现有主题色。 |

## 实现边界

`Sidebar.tsx` 保留原有树结构、分组、浮动侧边栏、原生窗口拖动区域和底部入口。行交互拆为 `SidebarTabRow.tsx`，命名输入复用 `SidebarRenameInput.tsx`。纯落点规则位于 `sidebarInteraction.ts`，拖拽与列表导航分别在两个 hook 中。

没有新增运行时依赖或持久化字段。移动仍调用现有 store API，关闭仍走 `closeTabAsking`。桌面行继续使用共享 Workbench 展示组件；Join 入口的交互没有在本轮扩展。

## 验收概览

| 验证什么 | 如何判断符合预期 |
| --- | --- |
| 排序和跨组移动 | 上方插前、下方插后；拖到分组最后一行下方仍属于该组；移动不激活被拖动的 tab。 |
| 分屏与取消拖拽 | 快速纵向拖动不误分屏；中部停留后有明确分屏提示；取消后无残留高亮。 |
| 固定网页和命名 | 连续点击、双击命名不跳回固定网址；只有显式重置按钮才返回。Escape 不保存改名。 |
| 多选与键盘 | 普通点击后 Shift 点击能选中整个可见范围；方向键只移动焦点，Enter 才激活。 |
| 长列表与视觉稳定 | 能拖向屏幕外位置；切换后能看到当前行；悬浮操作按钮不会挤动标题。 |
| 原有工作状态 | 固定 tab 关闭后仍保留条目，点击可唤醒；终端、文件的关闭确认和恢复仍按原规则工作。 |

### 详细操作

**排序与分屏：** 在一个分组里准备两个 tab，在 Today 准备两个。将 Today 中一项拖到分组第二项的下边缘，确认它成为该组最后一项。反向拖回 Today，确认位置和所属区正确。多选两项再重复，并拖回已选中的一项确认不会移到列表末尾。然后把一个可分屏 tab 拖到另一个的中部，先快速经过，再停留约半秒，分别确认排序与分屏提示。

**网页与命名：** 固定一个网页，导航到另一个地址；点击同一行两次，再双击标题命名，页面应保持当前位置。输入新名称后按 Escape，应恢复原名。用中文输入法输入并确认候选字，编辑框不应提前消失。最后点击 Return to pinned page，应只重置这一行对应的网页；从另一个当前 tab 点击该按钮也应定位正确。

**键盘与长列表：** 准备足够多的 tab 让侧边栏滚动。用 Tab 聚焦某一行，按上下键和 Home/End；当前内容不应随焦点移动而切换，Enter/Space 才激活。F2 改名，Shift+F10 打开菜单。通过已有全局切换命令选中屏幕外的 tab，确认侧边栏能定位；再拖动一项至列表边缘，确认持续滚动且释放后停止。

**工作状态：** 分别用固定终端、固定文件和 Today tab 验证关闭、唤醒与恢复。对正在运行任务的终端和有未保存编辑的文件，确认原有保护行为没有丢失。重启应用，确认分组、顺序和自定义标题按原有持久化规则恢复。

## 自动化验证与限制

新增纯函数测试覆盖落点、跨组尾部、自身落点、分屏区域、载荷校验和边缘滚动。组件测试覆盖激活与重置分离、选择锚点、重命名取消/IME、按钮隔离、键盘菜单和拖拽清理。Browser UI 新增真实鼠标排序/分屏、Shift 选择、命名、悬浮布局、长列表定位和固定条目休眠/唤醒测试，并附侧边栏截图。

浏览器 fixture 不能替代 macOS 原生 WKWebView 的焦点、触控板拖动手感和真实 PTY/文件生命周期验收；这些需按上面的桌面步骤验证。自动化检查状态以 PR 当前提交的检查结果为准。
